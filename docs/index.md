## What this guide covers

Agora lives in many repositories across two GitHub organizations: [`a-novel`](https://github.com/a-novel) for the writing studio, [`a-novel-kit`](https://github.com/a-novel-kit) for the shared libraries and tooling. The [stack repository](https://github.com/a-novel-kit/stack) brings them into one workspace, worked on through the `a-novel` CLI and AI agents that know the team's conventions.

1. **[Dependencies](/dependencies/)**: install your tools and get enrolled.
2. **[The a-novel CLI](/cli/)**: install it and clone the workspace.
3. **[Working with AI](/ai/)**: hand your tasks to an agent.
4. **[Runbooks](/cli/ui)**: do the work by hand.

Contributors need these four. [Sysadmins](/sysadmins/) have more to set up.

Ask questions on [Discord](https://discord.gg/rp4Qr8cA). Report security issues privately, through the [security policy](https://github.com/a-novel-kit/.github/blob/master/SECURITY.md).
