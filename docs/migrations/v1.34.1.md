# Upgrading to v1.34.1

The `a-novel` CLI drops `run stacks` and `run service status`, which v1.33.0 deprecated. Each one
duplicated another command. The replacements print the same tables.

## Do I need to act?

**Yes**, if a script, alias or note still calls either command. A removed command prints the help of
its parent and exits 0, so a script that calls one keeps running on the wrong output. Search for
both commands and replace each call as shown below.

## Replace `run stacks`

```bash
# before
a-novel run stacks

# after
a-novel core stacks list
```

## Replace `run service status`

```bash
# before
a-novel run service status service-json-keys

# after
a-novel run ps --service=service-json-keys
```

`run ps` takes the same `--stack` flag. A name that matches no service prints `(no services)` and
exits 0, where `run service status` failed. To check that a service exists, test whether
`run ps --service=<name> --json` prints a line.
